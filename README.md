> Built for engineers who need a perfectly symmetrical pair of parentheses and refuse to type them by hand.

## Features

- **Configurable size.** One integer, infinite possibilities (within reason).
- **Perfect symmetry.** Left and right are generated by the same f-string, so they can never drift apart.
- **Zero dependencies.** Ships with nothing, supports nothing, breaks nothing.
- **Blazing fast.** O(n) in `size`. Benchmarks available on request (they are not).

## Install

```bash
git clone https://github.com/brunomelani/BOOBS.git
cd BOOBS
```

## Usage

Open `tits.py`, set `size` to your preference, then run:

```bash
python tits.py
```

## Sample output

| `size` | Output |
|---|---|
| `0` | `(.)(.)` |
| `2` | `(  .  )(  .  )` |
| `5` | `(     .     )(     .     )` |
